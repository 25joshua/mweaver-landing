3단계로 완성

복잡한 설정 없이, 지문과 출제 포인트만 지정하면 됩니다.

1

지문 입력 & 출제 포인트 지정

영어 지문과 한글 해석을 입력합니다. 각 문제 유형별 전용 편집창에서 드래그, 클릭, 문단 분할 등으로 출제 포인트를 직접 지정합니다. 이 지정 자체가 우리 학교의 출제 경향을 반영하며, AI는 해당 포인트를 중심으로 문제를 생성합니다.

2

AI 맞춤형 생성

원하는 문제 유형을 선택하고 실행 버튼을 누르면, AI가 출제자가 지정한 포인트를 반영하여 내신 유형에 맞춘 문제, 정답, 해설을 자동 생성합니다. 개별 실행, 일괄 실행, 반복 실행으로 대량 출제도 가능합니다.

3

저장 및 출력

HTML, PDF, DOCX(한워드/MS Word), HWPX(한컴오피스 한글), 엑셀로 저장. 학생용/교사용 분리 출력 지원.

다운로드 및 체험 시작

자주 묻는 질문

Gemini API 키는 Google AI Studio에서 무료로 발급받을 수 있습니다. Mistral API 키는 Mistral AI Console에서 발급 가능합니다. 커스텀 슬롯은 OpenAI, Groq, OpenRouter 등 각 서비스 공식 웹사이트에서 API 키를 발급받아 입력하면 됩니다.
정품 인증 없이 300회까지 무료로 사용할 수 있습니다. 체험판 사용량은 서버에서 관리되며, 모든 기능을 동일하게 사용할 수 있습니다. 300회 소진 후에는 정품 인증이 필요합니다.
Multi-PC 버전은 1회 무료 PC 교체를 지원합니다. 카카오톡 문의를 통해 라이선스 해제 후 새 PC에서 재인증할 수 있습니다. 또한 구매 후 365일 경과 시 서버 연결 없이 영구 작동하는 오프라인 모드로 전환됩니다.
아닙니다. 유료 업데이트(15만원/년)는 신규 버전 다운로드 권한만 관리합니다. 업데이트를 갱신하지 않아도 현재 버전의 프로그램은 영구적으로 모든 기능을 사용할 수 있습니다.
무료로 시작하려면 Google Gemini 무료 티어를 추천합니다. 문법 분석 등 정확도가 중요한 작업에는 Fireworks AI DeepSeek V4 Flash($0.22/1M 입력 토큰)가 가성비가 좋습니다. 커스텀 슬롯에 OpenRouter를 설정하면 100개 이상의 모델을 하나의 API 키로 사용할 수 있습니다.
문제 생성을 위해서는 AI API 호출이 필요하므로 인터넷 연결이 필요합니다. 단, Ollama나 LM Studio를 커스텀 슬롯에 설정하면 로컬 AI 모델로 인터넷 없이 문제 생성이 가능합니다. 라이선스 검증은 구매 후 365일 경과 시 영구 오프라인 모드로 전환되어 서버 연결 없이 작동합니다.
PyInstaller로 빌드된 실행 파일은 일부 백신에서 오탐지될 수 있습니다. MWeaver는 악성코드가 포함되어 있지 않으며, Windows Defender 예외 설정 또는 관리자 권한 실행으로 해결할 수 있습니다.
