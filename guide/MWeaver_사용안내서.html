1. 프로그램 개요

MWeaver란?

MWeaver는 2개의 내장 AI 서비스와 4개의 사용자 정의 API 슬롯을 통합하여 영어 문제를 자동으로 생성하고, 체계적으로 관리할 수 있는 전문적인 교육 도구입니다.

🌟 주요 기능

AI 통합 플랫폼

2개 내장 AI + 4개 사용자 정의 API 슬롯

  • 내장 (2개):
  • Google Gemini
  • Mistral AI
  • 사용자 정의 (4개 슬롯):
  • OpenAI, Cohere (프리셋 제공)
  • Groq, OpenRouter, Together AI, DeepSeek
  • Fireworks AI

사용자 정의 4개 슬롯의 장점:

  • OpenAI 호환 API라면 URL과 API 키만 입력으로 즉시 연동
  • 4개 슬롯에 서로 다른 AI를 동시 설정, 라디오 버튼으로 1초 전환
  • 경쟁사는 1-2개 AI 고정이지만 MWeaver는 최대 6개 AI 자유 선택
  • Groq(초고속 무료), OpenRouter(100+ 모델), Fireworks AI(초저렴, 고품질) 등 다양한 무료 옵션
  • 새로운 AI 서비스 출시 시 업데이트 대기 없이 즉시 연동 가능

📚 문제 생성 시스템

객관식 9유형 + 영작·어순 배열 1유형 + 서답형 2유형 + 서술형 7유형 = 총 19유형

  • 객관식 (9유형):
  • 제목, 요지, 내용일치, 요약
  • 빈칸, 어휘, 밑줄 친 부분 의미 찾기
  • 문단 순서, 문장 위치
  • 영작·어순 배열 (1유형, 독자적):
  • 영작과 어순 배열
  • 서답형 (2유형):
  • 서답형 본문 요약
  • 서답형 어법 (괄호형 어법 + 어법 찾기)
  • 서술형 (7유형):
  • 지문 근거 단답형
  • 지칭 대상 문맥 이해형
  • 문장 변환형
  • 어휘 응용 문맥 수정형
  • 질문 답변 빈칸 완성형
  • 내용 설명 비교형
  • 주장 근거 해결방안형

서술형 출제 특징: 학생용 문제와 교사용 답지가 분리되어 출력되며, 교사용 답지에는 정답, 허용 답안, 지문 근거, 채점 기준, 부분 점수, 출제 의도가 자동 포함됩니다. 일괄 생성과 반복 실행도 지원됩니다.

📝 AI 문법 분석 학습 자료

영어 지문 문법 자동 분석 + 5가지 출력 형식

  • 50개 이상 문법 규칙 내장으로 각 문장의 문법 포인트 자동 분석
  • 5가지 출력 형식: 영어+한글+분석, 해석 TEST지, 단어 배열 TEST지, 빈칸 연습지, 영작 연습지
  • 영어+한글+분석 모드에 AI 요약과 주제 3가지 자동 생성
  • DOCX(한워드/MS Word), HWPX(한글 문서) 및 HTML로 저장하여 바로 배포 가능
  • 학생 자기 주도 학습용 자료로 활용

📖 어휘 학습 자료 및 테스트지

지문에서 핵심 어휘 자동 추출, 단어장/테스트지 생성

  • 수준(상/중/하)별 어휘 후보 자동 추출
  • AI로 맥락에 맞는 뜻, 유의어, 반의어 자동 생성
  • 단어장, 빈칸 연습, 매칭 테스트지 자동 생성
  • 정답지 별도 생성, 형식 자동 선택
  • DOCX(한워드/MS Word) 및 HTML로 저장하여 인쇄 바로 가능

커피 time (지문 관리 및 일괄 출제)

지문 은행 관리 + 일괄/반복 실행 + 학습자료 일괄 생성

  • 영어 지문과 한글 해석을 번호별로 체계적으로 관리
  • 여러 지문 선택 후 1, 2, 5, 8번 프롬프트 일괄 또는 반복 실행
  • 선택한 지문으로 학습자료(5가지 유형)를 HTML, PDF, DOCX, HWPX로 일괄 생성
  • 지문 더블 클릭 시 모든 편집창에 자동 입력
  • 영어/한글 문장 수 불일치 자동 감지 및 주황색 표시

📊 엑셀 문제 은행

체계적인 문제 관리

  • 단계별 분류
  • ID 기반 관리
  • 실시간 필터링
  • 편집 및 삭제

📄 DOCX / PDF / HTML 내보내기

전문적인 문제집 제작 및 편집

  • DOCX: 한워드, MS Word 호환 편집 가능
  • HWPX: 한글(hwp) 문서 호환, 한컴오피스에서 직접 편집 가능
  • HTML: 인쇄 최적화, 브라우저에서 직접 편집
  • PDF: 브라우저 인쇄로 PDF 저장
  • 학생용/교사용 분리 출력, 자동 포맷팅
  • 문제지, 정답지, 학습자료, 어휘자료 모두 출력

2. 설치 및 실행

📋 시스템 요구사항

  • 운영체제: Windows 10 이상 (64bit)
  • 메모리: 최소 4GB RAM 권장
  • 저장공간: 100MB 이상
  • 인터넷: API 사용을 위한 안정적인 연결

🚀 설치 방법

1 설치 파일 다운로드
MWeaver_Setup_1.2.1.exe 파일을 다운로드합니다. (Inno Setup 설치 파일)
2 설치 실행
다운로드한 파일을 실행합니다. Windows 보안 경고 화면이 나타나면 "추가 정보"를 클릭한 후 "실행" 버튼을 클릭합니다.
3 설치 완료
설치가 완료되면 바탕화면의 MWeaver 아이콘을 더블클릭하여 실행합니다.
⚠️ 주의사항:
  • 설치 중 Windows Defender가 경고를 표시할 수 있습니다. 이는 정상적인 현상입니다.
  • 바이러스 백신 프로그램에서 차단할 경우 예외 처리해주세요.
  • 첫 실행 시 라이선스 인증이 필요합니다.

상단 메뉴

메인 화면 상단에는 설정, 정품 인증, 업데이트 메뉴가 있습니다.

  • 설정: API 키 및 모델 설정
  • 정품 인증: 라이선스 등록 및 초기화 (구매 후 1년 이내 1회 무료 PC 교체 가능)
  • 업데이트: 최신 버전 확인 및 MYBOX 다운로드 페이지 열기

업데이트 체크 시 화면 상단 중앙에 컴팩트한 토스트 알림이 표시됩니다. 최신 버전이면 "현재 최신 버전을 사용 중입니다." 메시지가 표시되고, 새 버전이 있으면 안내 메시지와 함께 MYBOX 다운로드 페이지 링크를 제공합니다.

3. API 설정

🔑 API 키 발급 방법

Google Gemini (추천)

무료

장점: 무료, 한국어 지원 우수, 빠른 응답

1 AI Studio에서 Google 계정으로 로그인
2 "API 키 만들기" 버튼 클릭
3 생성된 API 키를 복사하여 MWeaver에 입력

⚡ Mistral AI

무료 티어

장점: 월 ~10억 토큰 무료, 오픈소스 기반, 효율적

1 Mistral Console에서 계정 생성
2 전화번호 인증 (카드 불필요)
3 API 키 생성 및 복사

🔧 사용자 정의 API 슬롯 (OpenAI 호환)

MWeaver는 2개 내장 API 외에 4개의 사용자 정의 API 슬롯을 제공합니다. OpenAI 호환 API를 제공하는 모든 서비스에 연결할 수 있습니다. OpenAI와 Cohere는 프리셋으로 제공되어 간편하게 설정할 수 있습니다.

⚡ Groq (추천)

무료 티어

장점: 초고속 추론 (초당 수백 토큰), 무료 티어 제공

1 Groq Console에서 계정 생성
2 API 키 생성
3 MWeaver 설정에서 사용자 정의 API 슬롯에 다음 입력:
  • API URL: https://api.groq.com/openai/v1
  • API 키: 발급받은 키
  • 모델: llama-3.3-70b-versatile 등

🌐 OpenRouter

무료 모델 포함

장점: 100+ 모델 통합 접속 (GPT, Claude, Gemini, Llama 등), 무료 모델 다수

1 OpenRouter에서 계정 생성
2 API 키 생성
3 MWeaver 설정에서 사용자 정의 API 슬롯에 다음 입력:
  • API URL: https://openrouter.ai/api/v1
  • API 키: 발급받은 키
  • 모델: "모델 리스트 불러오기" 버튼으로 조회 (스크롤바 지원)

Fireworks AI

초저렴

장점: DeepSeek-V3, Qwen2.5 등 고품질 오픈소스 모델 다수 지원, JSON/function calling 지원, 초저렴 가격

1 Fireworks AI에서 계정 생성
2 API 키 생성
3 MWeaver 설정에서 사용자 정의 API 슬롯에 다음 입력:
  • API URL: https://api.fireworks.ai/inference/v1
  • API 키: 발급받은 키
  • 모델: accounts/fireworks/models/deepseek-v3 등
💡 사용자 정의 API 슬롯 사용법:
  • 설정 화면에서 "사용자 정의 API 1~4 (OpenAI 호환)" 섹션에 정보를 입력합니다. OpenAI와 Cohere는 프리셋에서 선택하면 자동으로 설정됩니다.
  • 표시명: 원하는 이름 입력 (예: Groq, OpenRouter 등)
  • API URL: OpenAI 호환 엔드포인트의 Base URL 입력 (끝에 /chat/completions은 붙이지 마세요. 자동 추가됩니다.)
  • API 키: 각 서비스에서 발급받은 키 입력
  • 모델명: 직접 입력하거나 "모델 리스트 불러오기" 버튼으로 조회 (스크롤바가 있어 수백 개 모델도 빠르게 선택 가능)
  • URL 입력란 옆 ? 버튼을 클릭하면 입력 도움말이 표시됩니다.
  • 4개 슬롯에 서로 다른 서비스/모델을 동시에 설정하고 라디오 버튼으로 전환할 수 있습니다.
📋 지원 서비스 예시:
서비스 Base URL 특징
Groq https://api.groq.com/openai/v1 초고속 추론, 무료 티어
OpenRouter https://openrouter.ai/api/v1 100+ 모델, 무료 모델 포함
Together AI https://api.together.xyz/v1 오픈소스 모델, $5 크레딧
DeepSeek https://api.deepseek.com/v1 초저렴 가격
Fireworks AI https://api.fireworks.ai/inference/v1 초저렴, 고품질 오픈소스 모델

⚙️ MWeaver에서 API 설정

1 설정 창 열기
메인 화면에서 "API 설정" 버튼을 클릭합니다.
2 API 키 입력
각 AI 서비스의 "키 발급" 버튼을 클릭하여 발급 페이지로 이동한 후, 발급받은 API 키를 입력합니다.
3 모델 선택
"모델 리스트 불러오기" 버튼을 클릭하여 사용 가능한 모델을 확인하고 선택합니다.
4 사용할 API 선택
하단의 라디오 버튼에서 사용할 AI 서비스를 선택합니다.
5 설정 저장
"저장" 버튼을 클릭하여 설정을 저장합니다.
💡 팁:
  • 처음 사용자는 Gemini(무료)로 시작하는 것을 권장합니다.
  • API 키는 파일에 Fernet 암호화되어 저장되며, 입력창에서는 앞 6자와 뒤 4자만 부분 마스킹되어 표시됩니다.
  • API 키 입력창에서 Ctrl+C/X 또는 우클릭 복사는 차단되어 있어 전체 평문이 노출되지 않습니다.
  • 유료 API 사용 시 사용량을 정기적으로 확인하세요.
  • 사용자 정의 API 슬롯(4개)을 통해 OpenAI, Cohere, Groq(무료 티어, 초고속), OpenRouter(무료 모델 다수), Fireworks AI(초저렴, 고품질)를 추가로 사용할 수 있습니다.
  • 4개의 사용자 정의 슬롯에 서로 다른 서비스를 설정하고 라디오 버튼으로 즉시 전환할 수 있습니다.

4. 문제 생성

⚡ 각 편집창에서 빠르게 준비 (주요 방법)

MWeaver는 10개의 프롬프트별 전용 편집창을 제공합니다. 각 편집창에서 텍스트를 직접 편집하고 출제 준비를 할 수 있어, 빠르고 효율적인 문제 생성이 가능합니다.

📋 편집창 구조 및 특징

1 편집창 열기
왼쪽 패널에서 원하는 문제 유형의 "편집" 버튼을 클릭하면 해당 프롬프트 전용 편집창이 열립니다.
2 메모란 참고
각 편집창 최상단에 메모란이 표시되어 있습니다. 메모란은 각 문제 유형별 사용 방법이나 주의사항을 미리 확인하고 참고하는 용도입니다. 메모란은 수정해도 저장되지 않습니다.

  • [B형 어순] 버튼: 어순 배열 문제 출제 - 출제할 영어 문장만 드래그하여 선택

1 드래그 선택으로 출제 부분 표시

2 한글 해석 활용
한글 해석란은 AI가 참고하는 용도가 아니라, 출제자가 한글 해석을 읽고 출제 포인트를 색상으로 한 번만 표시해 두는 용도입니다. 예를 들어, 어휘 문제 출제할 부분은 보라색, 밑줄 친 부분의 의미 문제는 주황색, 빈칸 문제 출제할 부분은 초록색, 문장 위치 문제 출제할 부분은 회색 등으로 표시해 두면, 2, 3, 4, 9번 편집창 전체에 공유되므로 매번 해석을 다시 읽지 않고 표시된 색상만 보고 영어 텍스트에 빠르게 출제 지점을 표시할 수 있습니다.
3 여러 섹션 동시 작업
6번, 8번 편집창에서는 여러 텍스트를 동시에 준비할 수 있습니다. 각 섹션을 독립적으로 편집한 후 한 번에 전송하여 효율성을 높이세요.

🔁 반복 실행으로 대량 문제 생성

사용자 입력란에 준비된 내용을 "▶️ 반복 실행" 버튼으로 지정한 횟수만큼 자동으로 반복 실행할 수 있습니다. 매 회차마다 생성된 문제가 자동으로 저장소에 누적 저장되므로, 한 번의 클릭으로 대량의 문제를 순차적으로 생성할 수 있는 것이 가장 큰 장점입니다.

1 입력 준비
사용자 입력란에 [1번 프롬프트], [3번 프롬프트]와 같은 형식으로 실행할 내용을 준비합니다. (각 편집창의 "사용자입력란으로" 버튼을 사용하면 자동으로 이 형식으로 준비됩니다.)
2 횟수 및 간격 설정
입력란 하단의 "횟수" 스핀박스에서 반복할 횟수(1~99)를, "간격" 스핀박스에서 각 반복 사이의 대기 시간(1~30초)을 지정합니다. 간격을 두면 API 요청이 한꺼번에 몰려 제한(429 오류)에 걸리는 것을 방지할 수 있습니다.
3 반복 실행
"▶️ 반복 실행" 버튼을 클릭하면, 준비된 내용이 지정한 횟수만큼 설정된 간격으로 순차 반복 실행됩니다. 예를 들어 횟수를 20, 간격을 5초로 설정하면 클릭 한 번으로 20회 연속 문제가 생성되어 저장소에 쌓입니다.
4 중지 및 설정
실행 중에는 "중지" 버튼으로 언제든 중단할 수 있고, 완료된 회차까지의 결과는 그대로 저장소에 유지됩니다. ⚙️ 버튼을 클릭하면 반복 실행에 대한 상세 도움말과 설정을 확인할 수 있습니다.
💡 활용 팁:
  • 같은 지문으로 여러 유형의 문제를 대량 생성하거나, 다양한 지문을 하나씩 순서대로 돌려가며 자동으로 문제집을 채워나갈 때 유용합니다.
  • 일괄 실행(🚀)은 준비된 내용을 1회만 실행하는 반면, 반복 실행(▶️)은 동일한 준비 내용을 지정한 횟수만큼 반복하여 실행량을 크게 늘려줍니다.

저장소에 반복적으로 남아있는 불필요한 기호나 문구(예: 특정 표시, 중복 안내 문구 등)를 검색란을 이용해 한 번에 모두 찾아 삭제할 수 있습니다.

"삭제" 버튼을 클릭하면 현재 선택된(주황색) 모든 위치가 한 번에 삭제됩니다. 잘못 삭제했다면 "취소" 버튼으로 삭제 이전 상태로 되돌릴 수 있습니다.
💡 팁:
  • 대량 생성 후 저장소에 반복적으로 남는 불필요한 표시가 있다면, 검색-삭제 기능으로 한 번에 정리하세요

✍️ 서술형 출제

영어 지문을 바탕으로 AI가 서술형(주관식) 문제를 자동으로 생성하는 기능입니다. 기존 객관식·영작·어순·서답형 유형과 별도의 창에서 동작하며, 학생용 문제와 교사용 답지를 분리하여 HTML/DOCX로 저장할 수 있습니다.

지원 유형
  • 지문 근거 기반 단답형: 원인, 결과, 목적, 반응, 개념, 의미, 대상 등 지문 속 명시적 근거를 묻는 단답형
  • 지칭 대상·문맥 이해형: it, this, that, they, the former 등 지칭 표현의 실제 대상을 묻는 문제
  • 문장 변환형: 능동·수동, 화법, 시제, 관계사절·분사구문, 비교급·최상급 등 문법 구조 변환
  • 어휘 응용·문맥 수정형: 지문에 쓰인 어휘의 품사·형태 변환, 문맥에 맞는 연어·의미 수정
  • 질문·답변 빈칸 완성형: Q:/A: 형식의 질문·답변 문장에서 (A), (B), (C) 빈칸 채우기
  • 내용 설명·비교형: 지문 내용을 설명하거나 두 대상을 비교하는 서술형
  • 주장·근거·해결방안형: 지문 속 주장과 근거를 파악하고 해결방안을 제시하는 개방형 서술형
1 서술형 출제 창 열기
메인 화면의 '서술형 출제' 메뉴(또는 버튼)를 클릭하여 독립 창을 엽니다.
2 지문 입력 및 유형 선택
영어 지문을 입력한 뒤 출제할 서술형 유형과 문항 수를 선택합니다. 여러 유형을 조합하거나 단일 유형으로도 생성할 수 있습니다.
3 AI 생성 및 결과 확인
'생성' 버튼을 누르면 AI가 학생용 문제(question, conditions)와 교사용 답지(answer, acceptable_answers, evidence)를 분리해 출력합니다.
4 저장 및 배포
'HTML로 저장' 또는 'DOCX로 저장'으로 학생용/교사용 자료를 각각 저장하여 시험지 또는 답지로 활용합니다.

5. 학습 자료 제작 (한줄해석·문법 분석)

5가지 출력 형식 및 AI 자동 분석

영어 지문과 한글 해석을 입력하면 5가지 출력 형식의 학습 자료를 자동으로 생성하는 기능입니다. AI가 각 문장의 문법 포인트를 분석하고, 지문의 한 문장 요약과 주제어 3개를 자동으로 추출하여 학습 자료에 포함합니다. 생성된 자료는 HTML, PDF, DOCX, HWPX 형식으로 저장할 수 있어 수업 자료, 프린트 학습지, 온라인 학습 자료로 바로 활용할 수 있습니다. HWPX 형식은 한글(hwp) 문서와 호환되어 한컴오피스에서 직접 편집할 수 있습니다.

5가지 출력 형식
  • 영어+한글+분석: 각 문장을 영어 원문, 한글 해석, AI 문법 분석으로 구성하여 통합 학습 자료를 생성합니다. 상단에 AI가 생성한 한 문장 요약(영어/한글)과 주제어 3개(영어/한글)가 자동으로 포함됩니다.
  • 해석 TEST: 영어 문장만 표시하고 한글 해석 부분을 빈칸으로 남겨, 학생이 직접 번역을 작성하도록 하는 해석 시험지를 생성합니다.
  • 단어 배열: 각 문장의 핵심 단어들을 순서 섞어 제시하고, 학생이 올바른 어순으로 배열하도록 하는 어순 연습지를 생성합니다. A/B/C 3가지 버전이 자동으로 만들어집니다.
  • 빈칸연습: 각 문장에서 핵심 단어를 빈칸으로 만들어 문맥 파악 및 어휘 연습용 학습지를 생성합니다. A/B/C 3가지 버전이 자동으로 만들어집니다.
  • 영작: 한글 문장만 표시하고 영어로 번역(영작)하도록 하는 영작 시험지를 생성합니다.
AI 자동 분석 기능
  • AI 문법 분석: 각 문장에 포함된 중·고등학교 수준의 주요 문법 포인트를 AI가 자동으로 분석합니다. 분사구문, 관계사절, 접속사, 부정사, 동명사, 수동태, 병렬 구조 등을 문장 내 실제 표현, 문법 범주, 문장 내 역할, 의미로 구조화하여 출력합니다.
  • AI 한 문장 요약: 전체 지문을 한 문장으로 요약하여 영어와 한글로 자동 생성합니다. 학생이 지문의 핵심 내용을 빠르게 파악할 수 있도록 학습 자료 상단에 포함됩니다.
  • AI 주제어 3개 추출: 지문의 핵심 주제어 3개를 영어와 한글로 자동 추출하여 학습 자료에 포함합니다.
  • 50개 이상 내장 문법 규칙: AI 분석 외에도 50개 이상의 내장 문법 규칙이 적용되어 일관된 품질의 분석을 제공합니다. AI 분석 결과에 내장 규칙이 우선 적용됩니다.

입력 방식

  • 클립보드 붙여넣기: 영어 지문과 한글 해석을 [한글 해석] 구분자로 나누어 클립보드에 복사한 뒤 '붙여넣기' 버튼을 누르면, 영어와 한글이 자동으로 분리되어 각 입력창에 문장 번호와 함께 채워집니다.
  • 직접 입력: 왼쪽(영어 지문)과 오른쪽(한글 해석) 입력창에 각각 직접 입력할 수도 있습니다.
  • 매칭 조정: 영어와 한글 문장 수가 일치하지 않거나 잘못 짝지어진 경우, '매칭 조정' 버튼으로 문장 단위 매칭을 수동으로 조정할 수 있습니다. 프로그램이 자동으로 매칭 오류를 감지하여 경고합니다.
  • 어휘 추출/단어장 바로가기: 학습 자료 창 내에서 '어휘 추출/단어장' 버튼을 누르면 어휘 학습 자료 제작 기능으로 바로 이동하여 같은 지문의 어휘 학습 자료를 만들 수 있습니다.

사용 순서

1 기능 실행
메인 화면에서 '학습 자료' 메뉴(또는 버튼)를 클릭하면 '학습자료 제작 - 한줄해석' 창이 열립니다.
2 지문 입력
영어 지문과 한글 해석을 클립보드에 복사한 뒤 '붙여넣기' 버튼을 누르거나, 각 입력창에 직접 입력합니다. [한글 해석] 구분자를 기준으로 영어와 한글이 자동 분리됩니다.
3 출력 형식 선택
원하는 출력 형식(영어+한글+분석, 해석 TEST, 단어 배열, 빈칸연습, 영작)을 체크박스로 선택합니다. 여러 형식을 동시에 선택할 수 있으며, 선택한 모든 형식이 한 번에 생성됩니다.
4 자료 생성
'자료 생성' 버튼을 누르면 영어·한글 문장 쌍이 검증되고, '영어+한글+분석' 모드 선택 시 AI가 문법 분석, 한 문장 요약, 주제어 3개를 자동으로 생성합니다. '빈칸연습' 모드 선택 시 AI가 빈칸 단어를 자동 추출합니다.
5 미리보기 및 저장
생성된 자료는 하단 미리보기 창에서 확인할 수 있습니다. 저장 형식(DOCX, HTML, PDF)을 선택하고 '파일저장' 버튼을 누르면 선택한 형식으로 저장됩니다. '복사' 버튼으로 미리보기 내용을 클립보드에 복사할 수도 있습니다.

활용 팁

  • 수업 자료: '영어+한글+분석' 형식으로 지문 해석과 문법 분석이 포함된 통합 학습 자료를 만들어 수업 시간에 배포할 수 있습니다.
  • 숙제용 시험지: '해석 TEST' 또는 '영작' 형식으로 빈칸 해석지나 영작 시험지를 만들어 숙제로 활용할 수 있습니다.
  • 어순 연습: '단어 배열' 형식으로 어순 배열 연습지를 만들어 영어 어순 감각을 기를 수 있습니다. A/B/C 3가지 버전이 자동 생성되어 답안지를 분리 배포할 수 있습니다.
  • 어휘 연습: '빈칸연습' 형식으로 문맥 속 핵심 단어를 빈칸 처리한 학습지를 만들어 어휘 학습을 지원할 수 있습니다.
  • 편집 가능: 생성된 HTML 파일은 브라우저에서 더블 클릭으로 한글 해석 부분을 직접 편집할 수 있으며, DOCX 파일도 한글(HWP)이나 MS Word에서 열어 자유롭게 수정할 수 있습니다. AI 번역이나 문법 분석이 부정확한 경우 교사가 HTML 또는 DOCX 중 원하는 형식에서 쉽게 수정할 수 있습니다.
  • AI 분석 점검 (필수): AI 문법 분석 결과는 반드시 배포 전에 점검해야 합니다. 사용하는 AI 모델에 따라 분석 정확도가 달라지며, 잘못된 분석이 나올 가능성이 종종 있습니다. 단순한 오탈자 수준이 아니라 문법 범주나 문장 내 역할을 잘못 분석하는 경우도 있으므로, 학생에게 배포하기 전에 교사가 전체 분석 내용을 확인하고 수정하는 것을 강력히 권장합니다.

6. 어휘 학습 자료 제작

주요 구성

영어 지문에서 어휘 후보를 추출하고, AI로 뜻·유의어·반의어를 채워 단어 테스트지와 학습자료를 만드는 기능입니다. 학생들에게 배포해 먼저 학습할 수 있는 HTML/DOCX 자료를 바로 생성할 수 있습니다.

  • 어휘 추출: 수준(상/중/하)을 복수 선택하여 지문에서 후보 단어를 추출
  • AI 속성 채우기: 영어 지문 맥락에 맞는 뜻, 대체 가능한 유의어, 지문상 의미의 반의어를 자동 생성
  • 단어 테스트지: 영어→한국어, 한국어→영어, 빈칸 쓰기, 선택형, 문맥 빈칸 등 유형으로 시험지 생성
  • 학습자료 출력: '출제' 체크된 단어들의 영어 단어, 뜻, 유의어, 반의어를 표 형태 HTML/DOCX로 저장

사용 순서

1 기능 실행
메인 화면에서 '어휘 학습 자료' 메뉴(또는 버튼)를 클릭합니다.
2 지문 입력 및 추출
영어 지문을 붙여넣고, 원하는 수준(상/중/하)을 체크한 뒤 '어휘 추출'을 클릭합니다.
3 AI 속성 생성 (선택)
'AI로 뜻·유의어·반의어 채우기' 버튼을 누르면 지문 맥락을 반영한 뜻·유의어·반의어가 후보에 자동 입력됩니다.
4 출제 여부 설정
후보 목록에서 학습자료나 테스트에 포함할 단어의 '출제' 체크를 켭니다.
5 자료 생성
'학습자료 출력' 버튼을 누르면 HTML과 DOCX가 동시에 생성되며, HTML 창 상단의 '인쇄' 버튼으로 바로 인쇄할 수 있습니다. '단어 테스트지 생성' 버튼으로 시험지도 만들 수 있습니다.

7. 커피 time (지문 관리 및 일괄 출제)

커피 time이란?

'커피 time' 버튼은 메인 화면 저장소 패널에 위치하며, 영어 지문과 한글 해석을 체계적으로 관리하고, 선택한 지문에 대해 여러 프롬프트를 일괄 또는 반복 실행할 수 있는 통합 지문 관리 창입니다.

주요 기능
  • 지문 은행 관리: 영어 지문과 한글 해석을 번호별로 저장, 수정, 삭제, 대량 입력
  • 일괄 문제 생성: 여러 지문을 선택하고 1, 2, 5, 8번 프롬프트를 체크하여 한 번에 순차 실행
  • 반복 실행: 선택한 지문-프롬프트 조합을 지정한 횟수만큼 반복 실행
  • 학습자료 생성: 선택한 지문으로 5가지 학습자료 유형을 HTML, PDF, DOCX, HWPX 형식으로 일괄 생성
  • 편집창 자동 입력: 지문 목록에서 더블 클릭하면 6번 편집창을 제외한 모든 편집창에 자동 입력

지문 목록 관리

지문 목록 영역에서는 저장된 모든 지문을 번호, 영어 지문, 한글 해석 세 가지 열로 확인할 수 있습니다. Ctrl+클릭 또는 Shift+클릭으로 여러 지문을 동시에 선택할 수 있습니다.

지문 관리 버튼
  • 지문 추가: 새로운 지문을 번호, 영어, 한글과 함께 등록
  • 대량 입력: 여러 지문을 한 번에 입력 (번호별로 구분하여 일괄 등록)
  • 해석 대량 입력: 기존 지문에 한글 해석을 한 번에 일괄 입력
  • 지문 편집: 선택한 지문의 영어/한글 내용 수정
  • 지문 삭제: 선택한 지문을 목록에서 삭제
  • 전체 선택 / 선택 해제: 목록의 모든 지문을 한 번에 선택하거나 해제
불일치 표시
  • 영어 지문과 한글 해석의 문장 수가 일치하지 않는 경우, 해당 지문이 목록에서 주황색으로 표시되어 한눈에 확인할 수 있습니다.
  • 미리보기/수정란에서도 영어/한글 문장 수가 실시간으로 표시되며, 일치 여부가 색상(녹색/주황색)으로 안내됩니다.

미리보기 및 수정

지문 목록에서 지문을 클릭하면 하단의 미리보기/수정 영역에 영어 지문(좌)과 한글 해석(우)이 문장 번호와 함께 표시됩니다. 각 문장은 자동으로 번호가 부여되어 문장 단위 매칭을 쉽게 확인할 수 있습니다.

수정 기능
  • 폰트 크기 조절: 상단의 폰트 크기 스핀박스로 영어/한글 수정창의 글꼴 크기를 8~24pt로 조절
  • 실시간 문장 수 표시: 영어/한글 수정 내용을 타이핑할 때마다 문장 수가 실시간으로 갱신되어 일치 여부를 즉시 확인
  • 수정 저장: '수정 저장' 버튼으로 편집한 내용을 지문 은행에 반영
  • 취소: '취소' 버튼으로 편집 내용을 초기화
더블 클릭 자동 입력
  • 지문 목록에서 지문을 더블 클릭하면 해당 지문이 6번 편집창을 제외한 모든 편집창에 자동으로 입력됩니다.
  • 2, 3, 4, 9번 편집창, 학습자료 제작 창, 어휘 추출 및 단어장 제작 창에는 한글 해석도 함께 자동 입력됩니다.
  • 이 기능을 활용하면 지문을 각 편집창에 일일이 복사-붙여넣기할 필요 없이 한 번의 더블 클릭으로 모든 편집창에 지문을 배포할 수 있습니다.

프롬프트 선택 및 일괄/반복 실행

커피 time 창의 중간 영역에서 출제할 프롬프트와 학습자료 유형을 나란히 선택할 수 있습니다.

프롬프트 선택
  • 1번부터 10번까지의 프롬프트 중 1, 2, 5, 8번만 커피 time에서 직접 실행 가능합니다. (나머지 번호는 회색으로 비활성화됩니다.)
  • 여러 프롬프트를 동시에 체크할 수 있습니다. 예: 1번과 5번을 동시에 선택하면 각 지문마다 1번 실행 후 5번이 순차 실행됩니다.
  • 선택 일괄 실행: 선택한 지문 x 체크한 프롬프트 수만큼 순차적으로 한 번씩 실행됩니다. 예: 3개 지문 선택 + 2개 프롬프트 체크 = 총 6회 실행
  • 선택 반복 실행: 위 일괄 실행을 지정한 횟수만큼 반복합니다. 예: 3개 지문 x 2개 프롬프트 x 5회 반복 = 총 30회 실행

학습자료 생성

프롬프트 선택 영역 우측에서 학습자료 유형과 저장 형식을 선택한 후 '학습자료 생성' 버튼을 클릭하면, 선택한 지문마다 하나씩 학습자료 파일이 자동 생성됩니다.

학습자료 유형 (복수 선택 가능)
  • 영어+한글+분석: 영어 원문, 한글 해석, AI 문법 분석 통합 자료
  • 해석 TEST: 영어 문장만 표시, 한글 해석 빈칸
  • 단어 배열: 핵심 단어 순서 섞기, A/B/C 3버전 자동 생성
  • 빈칸연습: 핵심 단어 빈칸 처리, A/B/C 3버전 자동 생성
  • 영작: 한글 문장만 표시, 영어 영작 연습
저장 형식
  • HTML, PDF, DOCX, HWPX 중 하나를 선택 (라디오 버튼)
  • 파일명/제목은 '공통이름 + 지문번호 + 번' 형식으로 자동 지정됩니다. (예: 고2 모의고사 2025년 9월 20번)

활용 팁

  • 대량 출제 워크플로우: '대량 입력'으로 지문을 한 번에 등록 → 전체 선택 → 1, 2, 5, 8번 프롬프트 체크 → '선택 일괄 실행' 클릭. 한 번의 클릭으로 모든 지문에 대해 3종류 문제가 자동 생성됩니다.
  • 학습자료 일괄 생성: 시험 대상 지문을 모두 등록한 후 '전체 선택' → 학습자료 유형 체크 → '학습자료 생성' 클릭. 지문마다 별도 파일로 자동 저장됩니다.
  • 영어지문과 해석 일괄 등록: 지문을 먼저 대량 입력한 후 '해석 대량 입력'으로 한글 해석을 나중에 일괄 등록할 수 있습니다. 문장 수 불일치의 경우, 미리보기/수정란에서 수정하고 '수정저장'버튼을 클릭합니다.
  • 편집창 빠른 배포: 지문을 더블 클릭하면 모든 편집창에 자동 입력되므로, 각 편집창에서 드래그/클릭만으로 출제 준비를 마칠 수 있습니다.

8. 엑셀 문제 은행

📊 엑셀 문제 은행이란?

엑셀 문제 은행은 생성된 문제들을 체계적으로 분류하고 관리할 수 있는 시스템입니다. 문제를 출처별, 단원별, 문항별로 분류하여 나중에 쉽게 찾아 사용할 수 있습니다. Microsoft Excel 프로그램이 없어도 사용 가능하며, MWeaver 자체 기능으로 엑셀 파일을 생성하고 관리할 수 있습니다.

저장소 주요 버튼
  • 문제은행에 저장: 저장소의 문제를 엑셀 문제 은행에 저장합니다.
  • 문제불러오기: 엑셀 문제 은행에서 문제를 검색하고 저장소로 불러옵니다.
  • 문제은행관리: 엑셀 문제 은행의 문제를 편집하거나 삭제합니다.
  • DOCX/HWPX/PDF/HTML로 저장: 저장소의 문제를 DOCX(한워드/MS Word), HWPX(한글 문서), HTML로 출력하며, HTML은 브라우저에서 PDF로 저장할 수 있습니다.

💾 문제 저장하기

1 저장소에 문제 준비
저장소에 저장할 문제들이 있는지 확인합니다.
2 문제은행에 저장 버튼 클릭
저장소 패널의 "문제은행에 저장" 버튼을 클릭합니다.
3 엑셀 파일 선택
기존 엑셀 파일을 선택하거나 새 파일을 생성합니다.
4 분류 정보 입력
단계별 분류 다이얼로그에서 문제의 분류 정보를 입력합니다.
  • 1단계: 출처 유형 (모의고사, 교과서, 기타)
  • 2단계: 세부 분류 (년도, 월, 교과서명 등)
  • 3단계: 미리보기 및 확인
5 저장 완료
분류 정보 입력이 완료되면 문제가 엑셀 파일에 저장됩니다.

📂 문제 불러오기

1 문제불러오기 버튼 클릭
저장소 패널의 "문제불러오기" 버튼을 클릭합니다.
2 엑셀 파일 선택
불러올 엑셀 파일을 선택합니다.
3 필터링 조건 설정
단계별 필터링 시스템을 사용하여 원하는 문제를 찾습니다.
  • 1단계: 출처 유형 선택
  • 2단계: 세부 분류 선택
  • 3단계: 문제 미리보기 및 선택
4 문제 선택 및 불러오기
원하는 문제들을 선택하고 "확인" 버튼을 클릭합니다.

✏️ 문제 편집 및 관리

1 문제은행관리 버튼 클릭
저장소 패널의 "문제은행관리" 버튼을 클릭합니다.
2 편집할 문제 선택
왼쪽 목록에서 편집하고 싶은 문제를 선택합니다.
3 문제 내용 수정
오른쪽 편집 영역에서 문제 내용과 분류 정보를 수정합니다.
4 저장 또는 삭제
"저장" 버튼으로 변경사항을 저장하거나 "삭제" 버튼으로 문제를 삭제합니다.
💡 엑셀 문제 은행 활용 팁:
  • 문제마다 고유한 ID가 자동으로 부여되어 중복을 방지합니다.
  • 분류 정보를 정확히 입력하면 나중에 찾기 쉬워집니다.
  • 편집한 문제는 목록에서 파란색으로 표시됩니다.
  • 엑셀 파일은 Microsoft Excel, LibreOffice Calc 등에서 열 수 있습니다.

문제 필터링으로 시험지 만들기

엑셀 문제 은행에 저장된 문제들을 출처, 유형, 문항 등으로 필터링하면 원하는 구성의 시험지를 빠르게 만들 수 있습니다. 학생용 문제지만, 교사용 정답/해설지도 함께 또는 개별적으로 출력할 수 있습니다.

1 엑셀 문제 은행에서 불러오기
저장소 패널의 "문제불러오기" 버튼을 클릭하고 원하는 엑셀 파일을 선택하면 "문제 필터링" 창이 열립니다.
2 1단계: 출처 유형 선택
라디오 버튼으로 모의고사, 교과서, 부교재, 기타 중 하나를 선택합니다. 선택에 따라 2단계 입력 항목이 달라집니다.
3 2단계: 세부 분류 입력
선택한 출처 유형에 따라 세부 조건을 입력합니다.
  • 모의고사: 학년, 년도, 월, 문항(예: 23번)을 선택/입력합니다. 문항은 특정 문항 번호를 조회할 때 사용합니다.
  • 교과서: 교과서명, 출판사, 단원, 추가 정보를 입력합니다.
  • 부교재/기타: 출처명, 분류, 추가 정보를 입력합니다.
4 3단계: 문제 선택
미리보기 목록에서 직접 문제를 선택하거나, 아래 버튼으로 자동 선택할 수 있습니다.
  • 지정 수량 자동선택: 각 문제 유형 옆의 입력칸에 원하는 개수를 입력한 후 클릭하면, 조건에 맞는 문제 중에서 각 유형별로 지정한 수량만큼 무작위로 선택합니다.
  • 유형별 1문항씩: 조건에 맞는 문제들 중 각 문항(또는 유형)별로 1문항씩 자동 선택합니다.
  • 문항/유형별 1문항씩: 각 문항 번호 안에서 여러 유형 중 하나를 무작위로 골라 1문항씩 선택합니다. 문항당 한 문제씩 구성할 때 유용합니다.
  • 선택 초기화: 모든 자동/직접 선택과 입력 수량을 0으로 되돌립니다.

"이전에 선택한 문제 제외"를 체크하면 이미 출력에 사용된 문제(엑셀에 ($#%) 기호가 붙은 문제)가 자동 제외되어 중복 출제를 방지할 수 있습니다. "선택 기록 초기화" 버튼으로 언제든 중복 방지 기록을 지울 수 있습니다.

5 저장소로 가져오기
선택한 문제를 "확인" 버튼으로 저장소로 불러옵니다. 확인 시 선택된 문제는 엑셀에 중복 방지 기호가 자동으로 기록됩니다.
6 DOCX/HWPX/PDF/HTML로 시험지 출력
저장소 패널의 "DOCX로 저장", "HWPX로 저장" 또는 "PDF/HTML로 저장" 버튼을 클릭합니다. DOCX는 한워드/MS Word에서 바로 편집 가능하며, HWPX는 한컴오피스 한글에서 바로 편집 가능하고, HTML은 브라우저에서 인쇄 또는 PDF로 저장할 수 있습니다. 출력 형식을 선택할 수 있습니다.
  • 학생용: 문제지만 출력합니다. 마지막에 정답지가 별도 페이지로 포함됩니다.
  • 교사용: 각 문제 아래에 정답과 해설을 함께 출력합니다.
  • 둘 다 저장: 학생용과 교사용 파일을 모두 생성합니다. 저장 위치 선택은 한 번만 처리되며 두 파일은 같은 폴더에 저장됩니다.
머리말 입력 창에서는 시험지 제목과 첫 페이지 좌측에 표시할 로고 이미지를 설정할 수 있습니다.
7 인쇄 또는 PDF 저장
생성된 HTML 파일을 브라우저에서 열고 상단 리본의 "인쇄" 버튼을 클릭하거나 Ctrl+P를 누릅니다. "대상"에서 "PDF로 저장"을 선택하고 A4, 여백 "맞춤"으로 설정하면 PDF 파일로 저장됩니다.

모의고사 시험지 출력 예시

예시: 2025년 3월 모의고사 45분 시험지 만들기

  1. "문제불러오기"에서 모의고사용 엑셀 파일을 선택합니다.
  2. 1단계에서 "모의고사"를 선택하고, 2단계에서 학년=3학년, 년도=2025, 월=3월을 선택합니다. 문항은 전체를 선택합니다.
  3. "문항/유형별 1문항씩" 버튼을 클릭하면 각 문항별로 가능한 겹치지 않게 유형별로 문제가 선택됩니다. "확인" 버튼을 클릭하면 저장소로 문제가 불러와집니다.
  4. 위와 같이 자동으로 하지 않고, 출제하고자 하는 유형별로 문항 수를 정하고 싶을 경우에는, 3단계의 입력칸에 원하는 유형별 문항 수를 입력합니다. 예: 제목 2, 요지 2, 내용일치 3, 요약 2, 빈칸 3, 어휘 4, 밑줄친부분의미 2, 서답형본문요약 1, 영작과어순배열 2, 어법문제(서술형) 2, 문단순서 2, 문장위치 2, 어법문제 2, 기타 0.
  5. "지정 수량 자동선택" 버튼을 클릭하면 조건에 맞는 문제 중에서 입력한 수량만큼 자동으로 선택됩니다.
  6. "확인"을 눌러 저장소로 불러온 후, "DOCX로 저장" 또는 "PDF/HTML로 저장" - "학생용" 또는 "교사용" 또는 "둘다"를 선택하고 머리말에 "2025년 3월 모의고사"를 입력합니다.
  7. 브라우저에서 열어 인쇄 또는 PDF로 저장하면 학생용 시험지가 완성됩니다.

모의고사 특정 문항 집중 시험지 출력 예시

예시: 2026년 6월 모의고사 39번 집중 시험지 만들기

  1. "문제불러오기"에서 모의고사용 엑셀 파일을 선택합니다.
  2. 1단계에서 "모의고사"를 선택하고, 2단계에서 학년=3학년, 년도=2026, 월=6월을 선택하고 문항=39번을 입력합니다.
  3. 3단계에서 미리보기 목록에 표시된 39번 문제들을 확인합니다. 여러 유형의 39번 문제가 있을 경우:
    • 지정 수량 자동선택: 각 유형별 원하는 개수를 입력 후 클릭합니다. 예를 들어 제목 1, 요지 1, 내용일치 1, 빈칸 1 등으로 39번 문제 중 필요한 유형만 골라 구성합니다.
    • 유형별 1문항씩: 39번에 포함된 유형별로 1문항씩 자동 선택하여 다양한 유형을 균등하게 포함합니다.
  4. "확인"을 눌러 저장소로 불러온 후, "DOCX로 저장" 또는 "PDF/HTML로 저장" - "학생용" 또는 "교사용" 또는 "둘다"를 선택하고 머리말에 "2026년 6월 모의고사 39번 집중 훈련"을 입력합니다.
  5. 브라우저에서 열어 인쇄 또는 PDF로 저장하면 39번 집중 시험지가 완성됩니다.

단원별 쪽문제/주간 테스트 예시

예시: 공통영어1 동아출판(이병민) 3단원 주간 테스트

  1. "문제불러오기"에서 교과서용 엑셀 파일을 선택합니다.
  2. 1단계 "교과서"를 선택하고, 2단계에서 교과서=공통영어1 (2022 개정), 출판사=동아출판(이병민), 단원=3을 입력합니다.
  3. "유형별 1문항씩" 또는 "문항/유형별 1문항씩" 버튼으로 단원에 포함된 유형을 간단히 구성합니다.
  4. "확인" 후 "DOCX로 저장", "HWPX로 저장" 또는 "PDF/HTML로 저장" - "학생용" 또는 "교사용" 또는 "둘다"를 선택하여 출력합니다.

9. DOCX/HWPX/PDF/HTML 내보내기

� DOCX 내보내기 (한워드/MS Word 호환) — 권장

DOCX 저장 기능은 저장소의 문제를 한워드(Hancom Word) 및 Microsoft Word에서 바로 편집 가능한 DOCX 파일로 출력합니다. 실제 학교와 학원에서 가장 많이 사용하는 한워드와 MS Word에서 직접 열어 수정, 편집, 인쇄할 수 있어 추가 변환 작업이 필요 없습니다. 저장소, 학습 자료, 어휘 자료 출력 시 가장 우선적으로 사용할 것을 권장하는 형식입니다.

� PDF/HTML 내보내기란?

PDF/HTML 내보내기는 저장소의 문제를 학생용 또는 교사용 HTML 파일로 변환하는 기능입니다. 생성된 HTML은 브라우저에서 편집하거나 인쇄할 수 있고, 브라우저의 인쇄 기능을 통해 PDF로 저장할 수 있습니다.

DOCX 출력 대상
  • 문제지: 저장소의 객관식 문제를 DOCX로 출력
  • 정답지: 교사용 정답·해설지를 DOCX로 별도 출력
  • 서술형 문제: 서술형 출제 창에서 학생용/교사용 DOCX로 각각 저장
  • 학습 자료: AI 문법 분석 학습 자료를 DOCX로 출력
  • 어휘 자료: 단어장 및 어휘 테스트지를 DOCX로 출력

HWPX 내보내기 (한글 문서 호환) — 권장

HWPX 저장 기능은 저장소의 문제를 한컴오피스 한글(hwp)에서 바로 편집 가능한 HWPX 파일로 출력합니다. 한국 학교와 공공기관에서 널리 사용하는 한글 문서 포맷으로, 한글 프로그램에서 직접 열어 수정, 편집, 인쇄할 수 있어 추가 변환 작업이 필요 없습니다. 저장소, 학습 자료 출력 시 DOCX와 함께 권장하는 형식입니다.

HWPX 출력 대상
  • 문제지: 저장소의 객관식 문제를 HWPX로 출력
  • 정답지: 교사용 정답·해설지를 HWPX로 별도 출력
  • 서술형 문제: 서술형 출제 창에서 학생용/교사용 HWPX로 각각 저장

  • 파일이 다른 프로그램에서 열려있지 않은지 확인

11. 자주 묻는 질문

❓ 일반적인 질문

Q: 어떤 AI 서비스를 사용해야 하나요?

A: 처음 사용자는 Google Gemini(무료)로 시작하는 것을 권장합니다. 품질이 우수하고 한국어 지원이 좋습니다. 추가로 사용자 정의 API 슬롯을 통해 Groq(무료 티어, 초고속 추론), OpenRouter(무료 모델 다수), Fireworks AI(초저렴, 고품질)를 설정하여 사용할 수도 있습니다.

Q: 생성된 문제의 저작권은 누구에게 있나요?

A: AI가 생성한 문제의 법적 지위는 AI 제공자 계약과 한국 저작권법에 따라 달라집니다.

층위 결론
AI 제공자와의 계약 Gemini, Mistral, OpenAI, Cohere 등 주요 AI API 이용약관에서 출력물(Output)에 대한 권리를 사용자에게 양도하거나 사용을 허용하고 있습니다.
한국 저작권법상 보호 AI가 자동 생성한 결과물 그 자체는 저작권법상 저작물로 인정되지 않습니다. 즉, 상업적 판매는 가능하지만, 다른 사람의 복제를 막을 수 있는 저작권은 인정되지 않을 수 있습니다.
상업적 판매 실무 AI가 베껴 온 원저작물(기존 교과서, 수능 기출, 해설집 등)이 포함되었다면 저작권 침해 위험이 있습니다. 사용자가 직접 수정·선택·편집한 부분은 저작권 보호를 받을 수 있습니다.

따라서 "AI로 생성한 문제를 판매할 수 있느냐"는 기술적으로 가능하지만, "독점적 저작권을 주장할 수 있느냐"는 제한적입니다.

Q: 오프라인에서 사용할 수 있나요?

A: AI 문제 생성은 인터넷 연결이 필요하지만, 저장된 문제 관리와 HTML 내보내기는 오프라인에서 가능합니다. 구매 후 1년이 경과하면 서버와 무관하게 영구 작동하며, 1년 이내에는 서버 연결 실패 시에도 365일간 오프라인 유예가 제공됩니다.

PC 교체: 구매 후 1년 이내에 1회 무료 PC 교체가 가능합니다. 라이선스 초기화 메뉴를 통해 현재 PC의 라이선스를 해제한 후 새 PC에서 같은 라이선스 키로 인증하면 됩니다. 1년 경과 후에는 무료 교체가 불가하며, 추가 라이선스를 50% 할인가로 구매하실 수 있습니다.

Q: 업데이트는 어떻게 제공되나요?

A: 구매일로부터 1년간 모든 업데이트(기능 개선, 버그 수정, 새 AI API 대응)가 무상으로 제공됩니다. 1년 경과 후에는 연 15만원으로 업데이트를 연장할 수 있습니다(선택사항). 연장하지 않아도 마지막으로 업데이트된 버전을 영구적으로 사용할 수 있으며, 프로그램 기능이 제한되거나 중단되지 않습니다.

버전 및 프리셋 업데이트: 업데이트 연장 여부와 관계없이 버전 업데이트 체크와 프리셋 업데이트 기능은 계속 사용할 수 있습니다. 다만, 새로운 버전의 실제 설치와 새 프리셋 다운로드는 업데이트 기간(또는 연장 기간) 내에만 가능합니다.

OpenAI 호환 API: 사용자 정의 API 슬롯(4개)은 업데이트 연장 만료 후에도 계속 사용 가능합니다. 새로운 AI API 서비스가 출시되면 URL과 API 키만 입력하여 즉시 연동할 수 있습니다.

❓ 기술적인 질문

Q: Microsoft Excel이 없어도 사용할 수 있나요?

A: 네, 가능합니다. MWeaver는 Python 라이브러리로 엑셀 파일을 생성하므로 Microsoft Excel이 없어도 됩니다. LibreOffice Calc, Google Sheets 등에서 열 수 있습니다.

Q: API 사용량이 얼마나 되나요?

A: 문제 1개당 약 1000-3000 토큰을 사용합니다. Gemini 무료 버전은 월 150만 토큰까지 사용 가능하여 약 500-1500개 문제를 생성할 수 있습니다.

Q: MWeaver는 무료인가요?

A: 프로그램 자체는 유료로 구매합니다. 각 API마다 사용량에 따라 비용을 해당 AI사에 지불해야합니다. 그러나 각 API마다 무료 사용량이 상당하고, 무료 사용량 소진 후에 유료 사용시 비용은 저렴합니다. 유료/무료 사용량과 비용은 API설정창의 해당 버튼을 이용하면 각 API마다 정확한 정보를 보실 수 있습니다. 또한 API를 사용하는 것은 문제유형 1번부터 5번까지 입니다. 6번부터 10번까지는 내장 로직으로 동작하여 API를 사용하지 않기에 아무런 비용이 청구되지 않습니다.

Q: 생성된 문제를 수정할 수 있나요?

A: 네, 가능합니다. 저장소에서 직접 하실 수 있고, "문제은행관리" 버튼 클릭시 문제 관리 창이 나타납니다. 그곳에서 전문적인 관리도 가능합니다.

Q: HTML 파일이 제대로 인쇄되지 않아요

A: 브라우저의 인쇄 설정에서 "배경 그래픽" 옵션을 체크하고, 용지 크기를 A4로 설정해보세요. 또는 Ctrl+P를 눌러 인쇄 대화상자를 열고 설정을 조정한 후 인쇄합니다.
