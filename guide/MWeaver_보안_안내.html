MWeaver_Setup_v1.2.1 보안 안내서

⚠️ Windows 보안 경고 대응 가이드

MWeaver를 다운로드하고 실행할 때 Windows Defender SmartScreen에서 보안 경고가 나타날 수 있습니다. 이는 정상적인 현상이며, 아래 가이드를 따라 안전하게 해결할 수 있습니다.

📋 Windows 보안 경고 화면

※ 실제 Windows Defender SmartScreen 경고창

✅ 안전한 해결 방법

1단계: 경고 창의 "추가 정보" 또는 "More info" 버튼을 클릭합니다
↓
2단계: "실행" (Run anyway) 버튼 클릭
↓
3단계: MWeaver 설치 프로그램 실행

🔍 왜 이런 경고가 나타나나요?

✅ 정상적인 이유:

  • MWeaver는 개인 개발자가 만든 프로그램입니다
  • Microsoft에서 아직 서명하지 않은 프로그램입니다
  • 널리 알려지지 않은 새로운 프로그램입니다

❌ 위험한 경우가 아닙니다:

  • 바이러스나 악성코드가 아닙니다
  • 검증된 안전한 프로그램입니다

🛡️ MWeaver의 보안 특징

✅ 보안 검증 완료:

  • 바이러스 백신 검사 통과
  • 악성코드 검사 통과
  • 안전한 AI API만 사용
  • 개인정보 수집하지 않음

✅ 프로그램 특징:

  • 인터넷 연결은 AI API 호출용만 사용
  • 사용자 데이터는 로컬에만 저장
  • 외부 서버로 데이터 전송하지 않음
