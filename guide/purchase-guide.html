🎯 MWeaver란 무엇인가요?

MWeaver는 2개의 내장 AI 서비스와 4개의 사용자 정의 API 슬롯을 통합하여 영어 문제를 자동으로 생성하고, 체계적으로 관리할 수 있는 전문적인 교육 도구입니다. 기존의 수동적인 문제 제작 방식을 혁신하여, 교육자들이 더 효율적이고 체계적으로 영어 문제를 관리할 수 있도록 도와줍니다.

💡 주요 장점과 특징

🤖 2개 내장 + 4개 사용자 정의 API 통합 플랫폼

내장: Google Gemini, Mistral 등 2개의 AI 서비스를 하나의 플랫폼에서 통합 관리할 수 있습니다. 사용자 정의: 4개의 추가 슬롯에 OpenAI, Cohere(프리셋 제공), Groq, OpenRouter, Together AI, DeepSeek, Fireworks AI 등 OpenAI 호환 API를 자유롭게 설정할 수 있습니다. API 키만 교체하면 즉시 다른 AI 모델로 전환되며, 각 AI의 장점을 활용하여 최적의 문제를 생성할 수 있습니다. 경쟁사는 1-2개 AI로 고정되어 있어 선택권이 제한적입니다.

객관식 9유형 + 영작·어순 1유형 + 서답형 2유형

객관식 9유형: 제목, 요지, 내용일치, 요약, 빈칸, 어휘, 밑줄 친 부분 의미 찾기, 문단 순서, 문장 위치를 AI가 자동으로 생성합니다. 영작·어순 배열 1유형: 영작 문제와 어순 배열 문제를 독자적으로 생성합니다. 서답형 2유형: 서답형 본문 요약, 서답형 어법(괄호형 어법 + 어법 찾기)을 지원합니다. 일괄 생성 및 반복 실행 기능으로 대량 출제도 가능합니다.

✍️ 서술형 7가지 구조화 출제 (차별화 기능)

근거 단답형, 지칭 대상형, 문장 변환형, 어휘 문맥 수정형, 질문·답변 빈칸 완성형, 내용 설명·비교형, 주장·근거·해결방안형 등 7가지 서술형 유형을 구조화하여 자동 출제합니다. 학생용 문제와 교사용 답지가 분리되어 출력되며, 교사용 답지에는 정답, 허용 답안, 지문 근거, 채점 기준, 부분 점수, 출제 의도가 포함됩니다. 이 기능은 2026년 현재 시중 경쟁 제품에서 제공하지 않는 MWeaver만의 차별화 기능입니다.

📊 문제 은행 — 누적 자산 가치

엑셀 기반의 문제 은행 시스템으로 문제를 출처유형-학년-과목-문제유형-추가분류 5단계로 분류하여 체계적으로 관리할 수 있습니다. Microsoft Excel 없이도 독립 실행되며, 양방향 가져오기/내보내기, 복합 조건 검색, 실시간 미리보기를 지원합니다. 사용이 누적될수록 수천, 수만 개의 문제가 문제 은행에 자동 저장되어 하나의 거대한 데이터베이스가 됩니다. 이 누적된 문제 은행은 학원, 학교, 출판사 등에서 단순한 프로그램 가격을 넘어서는 엄청난 자산 가치를 가집니다. 필요한 문제를 검색하고 조합하여 몇 초 만에 완성된 문제지를 출력할 수 있습니다.

📚 AI 문법 분석 학습 자료 (차별화 기능)

영어 지문의 각 문장에 대해 50개 이상의 문법 규칙을 내장한 규칙 체계로 문법 포인트를 자동 분석합니다. 5가지 출력 형식을 지원합니다: 영어+한글+분석(통합 학습 자료), 해석 TEST지(빈칸 해석 시험지), 단어 배열 TEST지(어순 연습, A/B/C 3버전), 빈칸 연습지(핵심 단어 빈칸, A/B/C 3버전), 영작 연습지(한글→영어 영작 시험지). 영어+한글+분석 모드에는 AI 요약과 주제 3가지도 자동 생성됩니다.

�️ 이미지/PDF 지문 입력 (차별화 기능)

교과서·모의고사 지문을 사진, 캡처 이미지, PDF로 그대로 가져와 텍스트로 자동 변환합니다. 텍스트가 포함된 PDF는 API 호출 없이 로컬에서 무료 추출되고, 스캔본과 이미지는 Gemini 비전, Mistral OCR, 비전 지원 사용자 정의 API로 처리됩니다. 클립보드 캡처 이미지도 바로 추가할 수 있습니다. 추출 결과는 번호(21, 21번, [21], 3-1 등) 단위로 자동 분리되고 한글 부분은 같은 번호의 해석으로 매칭되어 커피 time 지문 목록에 저장됩니다. 미리보기에서 직접 수정·되돌리기 후 '새 지문으로 추가' 또는 '같은 번호 덮어쓰기'로 반영합니다.

🔍 생성 문제 교차 검증 (차별화 기능)

저장소에 생성된 문제를 생성에 사용한 AI와 다른 제2의 AI가 자동으로 점검합니다. 같은 AI가 만든 문제를 스스로 검수하면 오류를 놓치기 쉬우므로, 다른 AI의 관점으로 문항별 통과 / 검토 필요 / 오류 의심을 판정하고 지적 사항을 보고합니다. 출제 품질을 한 단계 높여주는 안전장치입니다.

�� 자동보내기 — 문항별 시험지 일괄 생성 (차별화 기능)

문제 필터링 창에서 문항을 복수 선택하고 실행하면 문항별 DOCX/HWPX 시험지 파일을 일괄 자동 생성합니다. 유형별 1문항씩(문항별 파일) 또는 문항/유형별 1문항씩(합본 파일) 방식을 지원하며, 학생용/교사용 동시 출력, 머리말·로고 자동 적용, 출력된 문제의 중복 방지 기록까지 자동으로 처리됩니다. 수십 개 문항의 자료를 수작업 없이 한 번에 제작할 수 있습니다.

🧩 시험지 블루프린트 자동 조합 (차별화 기능)

저장소의 '시험지 구성' 버튼으로 열리는 독립 창에서 출제 범위와 문항 구성(유형별 개수·문항당 배점)을 지정하면 문제 은행에서 시험지 한 부를 자동 조합합니다. 출처유형(모의고사·교과서·부교재·기타)을 복수 선택하고 학년·년도·월·문항·교과서·출판사·단원·출처명·분류·추가 조건을 행별로 조합합니다(행 내 AND, 행 간 OR — 예: "2025년 9월 20~24번 또는 2026년 3월 30~33번"). 목표 총점에 맞춘 배점 자동 분배, 기출제 문항 제외·지문 중복 방지·문항 섞기 옵션을 지원합니다. 부족한 문항은 AI가 자동 생성하는데, 이때 출제 범위 안에 있는 기존 문제들의 지문을 추출해 재료로 사용합니다(별도 지문 입력 불필요, 범위에 지문이 없으면 생성 건너뜀). 각 문항에 배점이 자동 표기되어 학생용+교사용 DOCX로 출력됩니다. AI 생성 문항은 문제 은행에 다시 저장할 수 있습니다.

📝 채점·분석 — OMR 자동 채점 (v1.3.0 신규, 차별화 기능)

출제를 넘어 시행 → 채점 → 분석 → 보강까지 한 프로그램에서 완결합니다. 전용 OMR 답안지로 시험을 치른 뒤 스캔 이미지나 PDF를 불러오면, 답안지에 인코딩된 시험코드로 해당 시험에 자동 매칭되고 학생 번호 마킹으로 명단과 연결되어 답안이 일괄 판독됩니다. 객관식·단답형은 자동 채점, 주관식 기입 박스는 AI 비전이 읽어 채점하며, 판정 O/X 클릭 한 번으로 수동 정정, 점수 직접 입력으로 부분 점수도 부여됩니다. 성적표·문항 분석표(문항별 정답률)를 엑셀로 저장하고, 개인별 오답 보강문제 출력: 학생 한 명을 선택해 실행하면 그 학생이 틀린 문항과 같은 지문·같은 유형의 문제를 문제은행에서 자동 추출해 저장소로 보내고, 그 학생 전용 보강지로 바로 출력할 수 있습니다. 학생별로 반복 실행하면 개인 맞춤 보강지를 만들 수 있습니다. 전원 보강지 일괄 저장: 버튼 한 번으로 오답이 있는 모든 학생의 보강지를 학년-반-이름 파일명의 개별 DOCX로 자동 생성·저장합니다 — 시험본 학생이 10명이면 보강지 10개가 한 클릭으로 완성됩니다.

⚡ 효율적인 워크플로우

일괄 생성 기능으로 1-10번 문제를 한 번에 실행할 수 있으며, 반복 실행과 자동 저장으로 대량 출제 시간을 획기적으로 단축합니다. 자동 분류 시스템으로 관리 시간도 절약됩니다.

🔒 데이터 보안

모든 데이터는 로컬에 저장되며, API 키는 Fernet 대칭 암호화로 안전하게 보관됩니다. 민감 파일은 SAFE_DIR 암호화 저장되며, 외부 서버에 문제 데이터가 전송되지 않습니다.

📈 사용함으로써 얻을 수 있는 이점

⏰ 시간 절약

  • 수동 문제 제작 시간을 80% 이상 단축
  • 제목, 요지, 내용일치, 요약, 문단 순서, 문장 위치 등은 30초 이내 출제 가능
  • 일괄 실행·반복 실행으로 여러 유형을 한 번에 동시 출제, 수 초 단위로 대량 생성
  • 자동 분류 시스템으로 관리 시간 절약
  • 템플릿 기반 작업으로 반복 작업 최소화

📚 교육 품질 향상

  • 2개 내장 AI(Gemini, Mistral) + 4개 사용자 정의 API 슬롯(OpenAI, Cohere, Groq, OpenRouter 등)의 장점을 자유롭게 활용한 고품질 문제 생성
  • 객관식 9유형 + 영작·어순 1유형 + 서답형 2유형 + 서술형 7유형으로 포괄적인 평가 가능
  • 서술형 구조화 출제로 채점 기준, 부분 점수, 출제 의도까지 자동 포함
  • AI 문법 분석 학습 자료로 학생 자기 주도 학습 지원
  • 어휘 단어장 및 테스트지 자동 생성으로 어휘 학습 효율화
  • 체계적인 5단계 분류 및 일관된 형식의 전문적인 문제집 제작
  • 출제 범위·유형·배점만 지정하면 문제 은행에서 시험지 한 부를 자동 조합하는 블루프린트 출제로 시험지 제작 시간 단축

💰 비용 효율성

  • 문제 유형 6-10번은 내장 로직으로 API 비용 없이 무제한 무료 사용
  • 2개 내장 AI API 모두(Gemini, Mistral)가 무료 티어 제공
  • 사용자 정의 API 슬롯(4개)으로 OpenAI(데이터 공유 시 무료 티어), Cohere(월 1,000회 무료), Groq(무료 티어), OpenRouter(무료 모델 다수), Fireworks AI(초저렴, 고품질) 추가 사용 가능
  • 일회 구매 45만원 영구 라이선스로 연간 필수 유지 비용 0원 (업데이트 연장 안 할 경우, 경쟁사 연 10~24만원)
  • 업데이트 연장 안 하면 5년 사용 시 경쟁사 대비 최대 75만원 절약. 연장해도 연 15만원으로 경쟁사보다 저렴
  • 외부 문제집 구매 비용 절약
  • 인쇄 및 배포 비용 최적화

🎯 편의성 및 접근성

  • 직관적인 사용자 인터페이스
  • 1년(365일) 오프라인 유예로 인터넷 단절 시에도 내장 로직 문제(6~10번)와 문제 은행, 저장 자료 조회/출력 가능 (AI 연동 기능은 오프라인 시 사용 불가)
  • Microsoft Excel 없이도 엑셀 파일 생성 및 관리
  • DOCX, HWPX, HTML, PDF, Excel 등 다양한 형식으로 문제 내보내기
  • 일괄 생성 및 반복 실행으로 대량 출제 자동화

MWeaver의 강점

  • 압도적 출제 속도: 개별 생성 30초~2분, 일괄·반복 실행 시 수 초 단위로 다수 유형 동시 출제
  • 객관식 9유형 + 영작·어순 1유형 + 서답형 2유형: 10개 프롬프트(AI 자동 생성 5 + 내장 로직 5)로 객관식 9유형 + 영작·어순 1유형 + 서답형 2유형 = 12유형의 모든 수능/내신 유형 커버
  • 서술형 7가지 구조화 출제: 학생용/교사용 분리 출력, 채점 기준·부분 점수·출제 의도 자동 포함
  • AI 문법 분석 학습 자료: 50개 이상 문법 규칙 내장, 5가지 출력 형식(영어+한글+분석, 해석 TEST지, 단어 배열 TEST지, 빈칸 연습지, 영작 연습지), AI 요약·주제 3가지 자동 생성
  • 어휘 학습 자료 자동 생성: 단어장, 빈칸 연습, 매칭 테스트지 자동 생성, 정답지 별도 출력
  • 2개 내장 + 4개 사용자 정의 AI API 자유 선택: 내장: Gemini, Mistral — 사용자 정의: OpenAI, Cohere(프리셋 제공), Groq, OpenRouter, Together AI, DeepSeek, Fireworks AI 등 OpenAI 호환 API 4개 슬롯 자유 설정 — API 키만 교체하면 즉시 전환

판매 약관 요약

MWeaver는 영구 라이선스 + 1년 업데이트 포함 + 선택 연장 방식으로 운영됩니다. 아래 약관을 반드시 확인하시기 바랍니다.

1. 영구 라이선스

  • 일회 구매 45만원 (1PC 기준): 구매 시 해당 버전의 프로그램을 영구적으로 사용할 수 있습니다.
  • 영구 사용 보장: 업데이트 연장 여부와 관계없이, 구매 시점의 프로그램(또는 업데이트 기간 내 마지막으로 업데이트된 버전)은 영구적으로 사용 가능합니다.
  • 연간 필수 유지 비용 0원: 구매 후 추가 비용 의무 없이 기존 버전을 계속 사용할 수 있습니다.
  • 라이선스 1PC 기준: 1개의 라이선스 키는 1대의 PC에서만 사용 가능하며, 동시 사용은 불가합니다.

2. 업데이트 정책

  • 구매일로부터 1년간 업데이트 무상 제공: 기능 개선, 버그 수정, 새로운 AI API 대응 등 모든 업데이트가 구매일로부터 1년간 무상으로 제공됩니다.
  • 1년 경과 후 업데이트 연장 (선택사항): 연 15만원으로 업데이트를 연장할 수 있습니다. 연장은 선택사항이며 의무가 아닙니다.
  • 연장하지 않은 경우: 마지막으로 업데이트된 버전을 영구적으로 사용할 수 있으며, 프로그램 기능이 제한되거나 중단되지 않습니다. 단, 새로운 업데이트(기능 개선, 버그 수정, 새 AI API 대응)는 제공되지 않습니다.
  • 업데이트 연장 후 1년 경과 시: 연장 기간이 종료되면 자동으로 연장되지 않으며, 별도 결제 시에만 연장됩니다. 연장 종료 후에도 마지막 버전 영구 사용이 보장됩니다.
  • 버그 수정 패치: 업데이트 기간(또는 연장 기간) 내에 발견된 버그는 무상으로 패치됩니다. 기간 종료 후 발견된 버그는 다음 업데이트 연장 시 처리됩니다.

3. OpenAI 호환 API 통합 (AI API 호환성 보장)

  • OpenAI 호환 API 표준 지원: MWeaver는 OpenAI 호환 API 표준을 채택하여, 향후 새로운 AI API 서비스가 출시되어도 사용자 정의 API 슬롯(4개)에 URL과 API 키만 입력하면 즉시 연동 가능합니다.
  • 개발자 개입 최소화: 새로운 AI API가 출시되더라도 프로그램 코드 수정 없이 사용자가 직접 URL과 API 키를 입력하여 대응할 수 있습니다.
  • 업데이트 연장 만료 후에도 유지: 업데이트 연장을 하지 않은 경우에도 기존 버전의 사용자 정의 API 슬롯 기능은 그대로 사용 가능합니다. 새로운 AI API 연동을 위한 프리셋 업데이트는 업데이트 연장 기간 내에만 제공됩니다.
  • 내장 AI API (Gemini, Mistral): 프로그램에 내장된 2개의 AI API는 업데이트 연장 여부와 관계없이 기존 버전에서 계속 사용 가능합니다. 단, API 제공사의 정책 변경(무료 티어 축소, 서비스 종료 등)으로 인해 사용이 제한될 수 있으며, 이는 MWeaver의 통제 범위 밖입니다.

4. 오프라인 사용 및 PC 교체 정책

  • 1년(365일) 오프라인 유예: 구매 후 서버 연결 실패 시에도 365일간 정상 작동합니다. 인터넷 단절 시에도 내장 로직 문제(6~10번), 문제 은행, 저장 자료 조회/출력이 가능합니다 (AI 연동 기능은 오프라인 시 사용 불가).
  • 영구 독립 모드: 구매 후 1년(365일) 경과 시 서버와 완전히 무관하게 영구 작동합니다. 서버 연결 없이도 프로그램이 정상 작동하며, 라이선스 검증이 서버를 통해 이루어지지 않습니다.
  • 1회 무료 PC 교체: 구매 후 1년 이내에 1회 무료로 PC 교체가 가능합니다. 라이선스 초기화 메뉴를 통해 현재 PC의 라이선스를 해제한 후 새 PC에서 같은 라이선스 키로 재활성화하면 됩니다.
  • 1년 경과 후 PC 교체: 1년 경과 후에는 무료 PC 교체가 불가하며, 추가 라이선스를 50% 할인가로 구매하셔야 합니다. 영구 독립 모드에서는 서버 연결이 필요하지 않으므로 기존 PC에서 계속 사용 가능합니다.

5. 추가 라이선스 할인 정책

  • 50% 할인: 추가 라이선스 구매 시 정가의 50% 할인가(22만 5천원)로 구매 가능합니다.
  • 개인 최대 3개: 개인(동일 구매자)당 최대 3개까지 추가 라이선스를 할인가로 구매할 수 있습니다.
  • 추가 라이선스도 동일 약관 적용: 추가 구매한 라이선스에도 영구 라이선스, 1년 업데이트 포함, 선택 연장, 1년 오프라인 유예, 영구 독립 모드가 동일하게 적용됩니다.

6. 체험판

  • 300회 무료 체험판: 구매 전 정품과 동일한 기능을 300회까지 무료로 테스트할 수 있습니다.
  • AI API 키만 설정: 체험판은 AI API 키만 설정하시면 모든 기능을 테스트할 수 있습니다.
  • 체험판 사용 후 구매 권장: 체험판으로 기능을 충분히 확인한 후 구매하시기를 권장합니다. 체험판 확인 후 구매한 경우 기능 관련 사유로 환불이 불가합니다.

약관 변경 및 종료

  • 약관 변경: 본 약관은 사전 공지 후 변경될 수 있으며, 기존 구매자에게 불리한 방향으로 소급 적용되지 않습니다.
  • 개발자 은퇴/서비스 종료 시: 개발자의 사정으로 인해 업데이트가 중단되더라도, 기존 버전의 영구 사용이 보장됩니다. 업데이트 연장제이므로 연장 수익이 멈추면 자연스럽게 업데이트가 중단되며, 이는 약속 위반이 아닙니다.
  • 서버 운영: 라이선스 검증 서버는 구매 후 1년간 운영되며, 1년 경과 후 영구 독립 모드로 전환되어 서버 의존성이 사라집니다. 서버 운영 중단 시에도 영구 독립 모드에서 프로그램이 정상 작동합니다.
