1. AI 문제 생성 기능

총 19유형 문제 자동 생성 통합

  • 객관식 9유형: 제목/요지/내용일치/요약/빈칸/어휘/밑줄의미/문단순서/문장위치
  • 영작·어순 1유형 + 서답형 2유형: 영작·어순배열, 본문요약, 어법
  • 서술형 5유형: 근거 단답형, 지칭 대상형, 문장 변환형, 어휘 문맥형, 빈칸 완성형

서술형 구조화 출제 차별화

학생용 문제와 교사용 답지가 분리되어 출력됩니다. 교사용 답지에는 정답, 허용 답안, 지문 근거, 채점 기준, 부분 점수, 출제 의도가 자동 포함됩니다.

2개 내장 + 4개 사용자 정의 API

내장: Gemini, Mistral. 사용자 정의: OpenAI, Cohere, Groq, OpenRouter, Together AI, DeepSeek, Fireworks AI 등 OpenAI 호환 API 4개 슬롯 자유 설정.

API 비용 없는 문제 유형 무료

6-10번 문제(어법, 브래킷, 배열, 삽입, 문법)는 내장 로직으로 AI API 호출 없이 완전 무료 생성.

무료 API 티어 활용

  • Gemini Flash-Lite: 일 1,000회 무료 (카드 불필요)
  • Mistral: 월 ~10억 토큰 무료 (전화 인증만)
  • 사용자 정의: Groq(무료 티어), OpenRouter(무료 모델 다수), Cohere(월 1,000회 무료) 등

일괄 생성 및 반복 실행

1-10번 프롬프트 일괄 실행 또는 지정 횟수 반복 실행. 커피 time으로 여러 지문 일괄 출제 가능.

2. 학습 자료 및 어휘 기능

영어+한글+문법 분석 통합 출력 차별화

50개 이상 문법 규칙 + AI 분석으로 각 문장의 문법 포인트 자동 추출. 영어 원문, 한글 해석, 문법 분석 통합 출력. AI 한 문장 요약과 주제어 3개도 자동 생성.

5가지 학습 자료 출력 형식

  • 영어+한글+분석 (AI 요약+주제 포함)
  • 해석 TEST지 (빈칸 해석)
  • 단어 배열 TEST지 (A/B/C 3버전)
  • 빈칸 연습지 (A/B/C 3버전)
  • 영작 연습지 (한글→영어)

어휘 학습 자료 생성

수준(상/중/하)별 핵심 어휘 자동 추출, AI로 뜻·유의어·반의어 생성. 단어장과 단어 테스트지(영한/한영/빈칸/선택형/문맥 빈칸) 자동 생성.

커피 time (지문 관리 및 일괄 출제)

영어 지문과 한글 해석을 번호별로 관리. 여러 지문 선택해 1, 2, 5, 8번 프롬프트 일괄/반복 실행. 학습자료 5가지 유형을 HTML/PDF/DOCX/HWPX로 일괄 생성.

3. 문제 은행 및 출력 시스템

엑셀 문제 은행 누적 자산

생성된 모든 문제가 5단계로 자동 분류되어 엑셀에 저장. Excel 없이도 MWeaver 자체 관리 가능. 누적될수록 수만 개의 문제 DB가 되어 핵심 자산이 됩니다.

DOCX 출력 (한워드/MS Word 호환)

문제지, 정답지, 학습자료, 어휘자료 모두 DOCX 출력. 한워드와 MS Word에서 직접 편집/인쇄 가능.

HWPX 출력 (한글 문서 호환)

한컴오피스 한글에서 직접 편집 가능한 HWPX 형식 출력.

HTML / PDF 출력

인쇄 최적화 HTML 출력, 브라우저에서 바로 인쇄 또는 PDF 저장 가능. HTML 파일은 브라우저에서 편집도 가능.

학생용/교사용 분리 출력

모든 출력 형식에서 학생용 문제지와 교사용 정답지를 별도 자동 생성.

복합 조건 검색

출처, 학년, 과목, 유형 등 다중 조건으로 문제 검색, 실시간 미리보기 제공.

5. 라이선스 및 운영

일회 구매 영구 사용 핵심

한 번 구매하면 해당 버전 영구 사용. 연 구독형과 달리 사용 중단 시 기능 상실이 없습니다.

1년 업데이트 무상 포함

구매일로부터 1년간 모든 업데이트 무상 제공. 1년 후 연 15만원 연장 가능(선택). 연장 안 해도 기존 버전 계속 사용.

오프라인 사용 지원

1년(365일) 오프라인 유예. 내장 로직 문제(6~10번), 문제 은행, 저장 자료 조회/출력 가능. 1년 경과 후 서버 무관 영구 작동. (AI API 연동 기능은 오프라인 시 사용 불가)

데이터 보안

민감 파일은 SAFE_DIR에 암호화 저장, API 키는 Fernet 대칭 암호화로 보호. 클라우드 의존 없이 로컬에서 안전하게 관리.

MWeaver 핵심 강점

비용 효율성

일회 구매 45만원으로 해당 버전 평생 사용. 업데이트 연장 안 하면 연간 0원. 사용 기간이 길수록 경제적 이점 증대.

전 기능 통합

AI 문제 생성(19유형) + 서술형(5유형) + 학습 자료 + 어휘 자료 + 문제 은행을 하나의 프로그램에 통합. 여러 소프트웨어를 따로 구독할 필요 없음.

서술형 구조화 출제

서술형 5유형 AI 자동 출제, 학생용/교사용 분리 출력, 허용 답안 검증, 채점 기준 및 부분 점수 포함.

영어+한글+문법 분석 통합 출력

50개 이상 문법 규칙 + AI 분석으로 각 문장 문법 포인트 자동 추출. 5가지 출력 형식을 한 번에 통합 생성.

2개 내장 + 4개 사용자 정의 API

내장(Gemini, Mistral) 외에도 OpenAI 호환 API 4개 슬롯 자유 설정. 새로운 AI 서비스 출시 시 즉시 연동 가능.

API 비용 절감

6-10번은 내장 로직으로 완전 무료. 1-5번도 Gemini Flash-Lite(일 1,000회 무료) 또는 Mistral(월 ~10억 토큰 무료)로 비용 없이 대량 생성 가능.

문제 은행의 누적 자산 가치

생성된 모든 문제가 자동 분류 저장되어 수천~수만 개의 문제 DB 구축. 45만원을 넘어서는 핵심 자산 가치.

영구 라이선스 + 오프라인 유예

일회 구매 영구 사용, 1년 오프라인 유예. 1년 경과 후 서버 무관 영구 작동. 연 구독형과 달리 중단 시 기능 상실 없음.

장기 투자 가치

사용 기간이 길수록 경제적 이점 증대. 문제 은행 누적 문제 수가 늘어날수록 전체 시스템 가치가 기하급수적으로 증가.

참고사항

- MWeaver 가격은 2026년 8월 기준 1PC 영구 라이선스 45만원입니다.

- API 사용 비용은 AI 기반 문제 생성(1-5번, 서술형, 문법 분석, 어휘 자료) 시 별도 발생하며, 무료 티어 활용 시 비용 없이 사용 가능합니다.

- 문제 유형 6-10번은 API 비용 없이 완전 무료입니다.

- 사용자 정의 API 슬롯(4개)으로 OpenAI 호환 API라면 모든 서비스 연동 가능. OpenAI, Cohere, Groq, OpenRouter, Together AI, DeepSeek, Fireworks AI 등 자유 구성.

- 무료 API 티어 정보는 2026년 8월 기준 추정치이며, API 제공사 정책은 수시로 변경될 수 있습니다. 정확한 정보는 각 API 제공사 공식 홈페이지에서 확인 바랍니다.

- AI 문법 분석 결과는 배포 전 점검이 권장됩니다.
