1. AI 문제 생성 기능

총 19유형 문제 자동 생성 통합

  • 객관식 9유형: 제목/요지/내용일치/요약/빈칸/어휘/밑줄의미/문단순서/문장위치
  • 영작·어순 1유형 + 서답형 2유형: 영작·어순배열, 본문요약, 어법
  • 서술형 5유형: 근거 단답형, 지칭 대상형, 문장 변환형, 어휘 문맥형, 빈칸 완성형

서술형 구조화 출제 차별화

학생용 문제와 교사용 답지가 분리되어 출력됩니다. 교사용 답지에는 정답, 허용 답안, 지문 근거, 채점 기준, 부분 점수, 출제 의도가 자동 포함됩니다.

2개 내장 + 4개 사용자 정의 API

내장: Gemini, Mistral. 사용자 정의: OpenAI, Cohere, Groq, OpenRouter, Together AI, DeepSeek, Fireworks AI 등 OpenAI 호환 API 4개 슬롯 자유 설정.

API 비용 없는 문제 유형 무료

6-10번 문제(어법, 브래킷, 배열, 삽입, 문법)는 내장 로직으로 AI API 호출 없이 완전 무료 생성.

무료 API 티어 활용

  • Gemini Flash-Lite: 일 1,000회 무료 (카드 불필요)
  • Mistral: 월 ~10억 토큰 무료 (전화 인증만)
  • 사용자 정의: Groq(무료 티어), OpenRouter(무료 모델 다수), Cohere(월 1,000회 무료) 등

일괄 생성 및 반복 실행

1-10번 프롬프트 일괄 실행 또는 지정 횟수 반복 실행. 커피 time으로 여러 지문 일괄 출제 가능.

이미지/PDF 지문 입력 차별화

지문 사진·캡처 이미지·PDF에서 텍스트 자동 추출. 텍스트 레이어 PDF는 API 없이 로컬 무료 추출, 스캔본은 Gemini 비전/Mistral OCR/사용자 정의 비전 API로 처리. 번호 단위 자동 분리 + 한글 해석 매칭으로 커피 time 지문 목록에 바로 저장.

생성 문제 교차 검증 차별화

저장소의 생성 문제를 생성 AI와 다른 제2의 AI가 자동 점검. 문항별 통과/검토 필요/오류 의심 판정과 지적 사항 보고.

2. 학습 자료 및 어휘 기능

영어+한글+문법 분석 통합 출력 차별화

50개 이상 문법 규칙 + AI 분석으로 각 문장의 문법 포인트 자동 추출. 영어 원문, 한글 해석, 문법 분석 통합 출력. AI 한 문장 요약과 주제어 3개도 자동 생성.

5가지 학습 자료 출력 형식

  • 영어+한글+분석 (AI 요약+주제 포함)
  • 해석 TEST지 (빈칸 해석)
  • 단어 배열 TEST지 (A/B/C 3버전)
  • 빈칸 연습지 (A/B/C 3버전)
  • 영작 연습지 (한글→영어)

어휘 학습 자료 생성

수준(상/중/하)별 핵심 어휘 자동 추출, AI로 뜻·유의어·반의어 생성. 단어장과 단어 테스트지(영한/한영/빈칸/선택형/문맥 빈칸) 자동 생성.

커피 time (지문 관리 및 일괄 출제)

영어 지문과 한글 해석을 번호별로 관리. 여러 지문 선택해 1, 2, 5, 8번 프롬프트 일괄/반복 실행. 학습자료 5가지 유형을 HTML/PDF/DOCX/HWPX로 일괄 생성.

3. 문제 은행 및 출력 시스템

엑셀 문제 은행 누적 자산

생성된 모든 문제가 5단계로 자동 분류되어 엑셀에 저장. Excel 없이도 MWeaver 자체 관리 가능. 누적될수록 수만 개의 문제 DB가 되어 핵심 자산이 됩니다.

DOCX 출력 (한워드/MS Word 호환)

문제지, 정답지, 학습자료, 어휘자료 모두 DOCX 출력. 한워드와 MS Word에서 직접 편집/인쇄 가능.

HWPX 출력 (한글 문서 호환)

한컴오피스 한글에서 직접 편집 가능한 HWPX 형식 출력.

HTML / PDF 출력

인쇄 최적화 HTML 출력, 브라우저에서 바로 인쇄 또는 PDF 저장 가능. HTML 파일은 브라우저에서 편집도 가능.

학생용/교사용 분리 출력

모든 출력 형식에서 학생용 문제지와 교사용 정답지를 별도 자동 생성.

자동보내기 (문항별 파일 일괄 생성) 차별화

문제 필터링 창에서 문항을 복수 선택하고 실행하면 문항별 시험지 파일을 DOCX/HWPX로 일괄 자동 생성. 유형별 1문항씩(문항별 파일) 또는 문항/유형별 1문항씩(합본 파일) 방식, 학생용/교사용 동시 출력, 머리말·로고 자동 적용, 출력 문제 중복 방지 기록까지 한 번에 처리. 수십 개 문항의 자료를 수작업 없이 한 번에 제작.

시험지 블루프린트 자동 조합 차별화

출제 범위(출처유형·학년·년도·월·문항·교과서·출판사·단원 등 복수 조건, 조건 행 추가로 AND/OR 조합)와 문항 구성(유형별 개수·문항당 배점, 목표 총점에 맞춘 배점 자동 분배)을 지정하면 문제 은행에서 시험지 한 부를 자동 조합. 기출제 문항 제외·지문 중복 방지·문항 섞기 옵션, 부족 문항 AI 자동 생성(출제 범위 내 기존 문제의 지문을 추출해 재료로 사용), 각 문항 배점 자동 표기 후 학생용+교사용 DOCX 동시 출력, AI 생성 문항은 은행에 재저장 가능.

복합 조건 검색

출처, 학년, 과목, 유형 등 다중 조건으로 문제 검색, 실시간 미리보기 제공.

4. 시험 채점·분석 기능

채점·분석 (OMR 자동 채점) v1.3.0 신규

저장소의 '채점·분석' 버튼 하나로 시험 시행부터 채점·분석·보강까지 완결합니다. 전용 OMR 답안지로 시험을 치른 뒤 스캔 이미지나 PDF를 불러오면 답안지에 인코딩된 시험코드로 해당 시험에 자동 매칭되고, 학생 번호 마킹으로 명단과 연결되어 답안이 일괄 판독됩니다.

자동 채점 + AI 주관식 채점

객관식 버블과 단답형은 자동 채점, 답안지 주관식 기입 박스는 크롭 이미지를 AI 비전이 읽어 자동 입력·채점합니다. 판정 O/X 클릭으로 즉시 정정, '점수(수동)' 칸 입력으로 부분 점수·예외 점수도 반영됩니다.

성적표·문항 분석표

학생별 총점·문항별 정오 기록과 문항별 정답률 분석표를 엑셀로 저장. 어느 문항에서 오답이 몰렸는지 한눈에 파악할 수 있습니다.

개인별 오답 보강문제 출력

채점 결과에서 학생 한 명을 선택해 실행하면, 그 학생이 틀린 문항과 같은 지문·같은 유형의 문제를 문제은행에서 자동 추출해 저장소로 출력 — 추출 건수 확인 후 저장소에 추가되고, '문제보내기'로 그 학생 전용 보강지를 즉시 출력합니다. 학생별로 반복 실행해 개인 맞춤 보강지를 만들 수 있습니다. (모의고사: 학년+년도+월+문항 / 교과서: 출판사+단원+추가 / 부교재·기타: 출처명+분류+추가 기준)

전원 보강지 일괄 저장 (학생별 DOCX)

개인별 출력과 별도로, '전원 보강지 일괄 저장' 버튼 한 번으로 오답이 있는 학생들의 보강지를 학년-반-이름 파일명의 개별 DOCX 파일로 자동 저장합니다. 회분(1·2·3회분)과 대상 학생을 일괄 또는 개별 선택할 수 있고, 오답 1문항당 보강 1문항이 배정되어 회분마다 다른 문제로 반복 보강지를 만들 수 있습니다. 출력 형식·머리말·템플릿과 저장 폴더를 한 번만 선택하면 완성됩니다. 10명이면 10개 파일이 한 클릭으로 나옵니다.

6. 라이선스 및 운영

일회 구매 영구 사용 핵심

한 번 구매하면 해당 버전 영구 사용. 연 구독형과 달리 사용 중단 시 기능 상실이 없습니다.

1년 업데이트 무상 포함

구매일로부터 1년간 모든 업데이트 무상 제공. 1년 후 연 15만원 연장 가능(선택). 연장 안 해도 기존 버전 계속 사용.

오프라인 사용 지원

1년(365일) 오프라인 유예. 내장 로직 문제(6~10번), 문제 은행, 시험지 자동 조합(AI 생성 옵션 제외), 저장 자료 조회/출력 가능. 1년 경과 후 서버 무관 영구 작동. (AI API 연동 기능은 오프라인 시 사용 불가)

데이터 보안

민감 파일은 SAFE_DIR에 암호화 저장, API 키는 Fernet 대칭 암호화로 보호. 클라우드 의존 없이 로컬에서 안전하게 관리.

MWeaver 핵심 강점

비용 효율성

일회 구매 45만원으로 해당 버전 평생 사용. 업데이트 연장 안 하면 연간 0원. 사용 기간이 길수록 경제적 이점 증대.

전 기능 통합

AI 문제 생성(19유형) + 서술형(5유형) + 학습 자료 + 어휘 자료 + 문제 은행을 하나의 프로그램에 통합. 여러 소프트웨어를 따로 구독할 필요 없음.

서술형 구조화 출제

서술형 5유형 AI 자동 출제, 학생용/교사용 분리 출력, 허용 답안 검증, 채점 기준 및 부분 점수 포함.

영어+한글+문법 분석 통합 출력

50개 이상 문법 규칙 + AI 분석으로 각 문장 문법 포인트 자동 추출. 5가지 출력 형식을 한 번에 통합 생성.

2개 내장 + 4개 사용자 정의 API

내장(Gemini, Mistral) 외에도 OpenAI 호환 API 4개 슬롯 자유 설정. 새로운 AI 서비스 출시 시 즉시 연동 가능.

API 비용 절감

6-10번은 내장 로직으로 완전 무료. 1-5번도 Gemini Flash-Lite(일 1,000회 무료) 또는 Mistral(월 ~10억 토큰 무료)로 비용 없이 대량 생성 가능.

문제 은행의 누적 자산 가치

생성된 모든 문제가 자동 분류 저장되어 수천~수만 개의 문제 DB 구축. 45만원을 넘어서는 핵심 자산 가치.

시험지 블루프린트 자동 조합

출제 범위와 유형별 문항 수·배점만 지정하면 문제 은행에서 시험지 한 부를 즉시 조합. 부족 문항 AI 자동 생성, 학생용/교사용 DOCX 동시 출력.

영구 라이선스 + 오프라인 유예

일회 구매 영구 사용, 1년 오프라인 유예. 1년 경과 후 서버 무관 영구 작동. 연 구독형과 달리 중단 시 기능 상실 없음.

장기 투자 가치

사용 기간이 길수록 경제적 이점 증대. 문제 은행 누적 문제 수가 늘어날수록 전체 시스템 가치가 기하급수적으로 증가.

참고사항

- MWeaver 가격은 2026년 8월 기준 1PC 영구 라이선스 45만원입니다.

- API 사용 비용은 AI 기반 문제 생성(1-5번, 서술형, 문법 분석, 어휘 자료) 시 별도 발생하며, 무료 티어 활용 시 비용 없이 사용 가능합니다.
