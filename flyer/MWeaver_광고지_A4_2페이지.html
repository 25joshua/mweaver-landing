워크시트 · 학습 자료 자동 생성

한줄해석 + AI 문법 분석(50+ 내장 문법 규칙 결합), 해석 TEST지, 단어 배열 TEST지, 빈칸 연습지, 영작 연습지를 지문 하나로 자동 제작. 수업 자료와 과제지를 별도 작업 없이 바로 출력합니다.

📚

어휘 학습 자료

지문에서 어휘 후보를 자동 추출하고, AI가 문맥에 맞는 의미·유의어·반의어를 생성합니다. 단어장과 단어 테스트지를 자동 제작하여 어휘 평가 준비 시간을 줄입니다.

📊

엑셀 문제은행 + 자동보내기 차별화

생성된 문제를 엑셀에 축적하고 출처·학년·유형 등 조건별 필터링으로 검색. 자동보내기로 문항을 복수 선택하면 문항별 DOCX/HWPX 시험지 파일을 일괄 자동 생성 — 머리말·로고 적용, 학생용/교사용 동시 출력, 출제된 문제 중복 방지 기록까지 한 번에 처리됩니다.

🖨️

5가지 출력 포맷 · 학생용/교사용 분리

DOCX(한워드·MS Word 호환) · HWPX · PDF · HTML · Excel로 출력. 모든 출력에서 학생용 문제지와 교사용 정답·해설지를 자동 분리 생성합니다.

3단계로 완성
1

지문 입력 · 포인트 지정

영어 지문과 해석을 입력하고 유형별 편집창에서 출제 포인트를 지정합니다.

2

AI 자동 생성

개별·일괄·반복 실행으로 19개 유형을 생성. 내장 AI + 커스텀 슬롯으로 무료 모델 포함 다양한 AI 선택.

3

출력 · 문제은행 축적

DOCX/HWPX 등으로 출력하고 문제은행에 저장해 다음 시험에 재활용합니다.
